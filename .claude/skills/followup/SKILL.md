# Сопровождение решения (S8)

## После принятия стратегии

1. Заведи карточку решения: `python3 tools/registry.py next-id projects/<имя> DEC`, запись в `state/decisions.md`:

```
## DEC-01
- Решение: <что решили, одним предложением>
- Почему: CLM-012, CLM-015, CLM-021
- Отвергнуто: «оставить как есть» — <почему>; вариант 3 — <почему>
- Кто и когда: <роль>, ГГГГ-ММ-ДД
- Обязательства:
  - [ ] <что сделать> · <кто> · ГГГГ-ММ-ДД · <метрика>
- Пересмотреть, если: ГГГГ-ММ-ДД; <порог метрики>; <событие на рынке>
- Состояние: действует
```

2. **Обязательства** бери из плана проверки и стратегии: у каждого — ответственный (роль, без имён), срок и метрика.
3. **Условия пересмотра:** дата и хотя бы одно событие или порог метрики, при котором решение нужно проверить раньше.
4. check, снимок `S8`.

## По команде «статус» или «что решаем сейчас»

5. Выполни `python3 strateg.py status <имя>`. Он покажет просроченные обязательства, решения с наступившей датой пересмотра и источники старше 90 дней (порог — `--days`).
6. Собери `output/status.md`:
   - что просрочено;
   - что наступает в ближайшие 14 дней;
   - какие основания решения устарели: источники старше 90 дней, прогнозы, которые не подтвердились, отозванные утверждения;
   - **что решать сейчас** — 1–3 пункта с вариантами ответа.
7. В чат — 3–6 строк. Если основания устарели, предложи S9.
