## Только для Claude Code

- Сводку о проекте при старте сессии показывает хук из `.claude/settings.json`. Если она уже есть в начале разговора, не запускай `status --brief` повторно.
- **Нет сводки хука — сессия открыта не в папке агента** (например, папку прикрепили через @ в другой сессии). Тогда не работают хук, роли субагентов из `.claude/agents/` и права из `.claude/settings.json`. Скажи одной строкой: «Откройте новую сессию в папке агента: <полный путь к папке со strateg.py>». Если пользователь хочет продолжать так — продолжай: роли critic, researcher, persona запускай обычными субагентами, передавая им текст файла роли.
- **Графики показывай сразу.** В приложении Claude отправь пользователю `output/charts/<id>.html` или `output/report.html` инструментом отправки файлов с показом, если он есть; в терминале — `open <файл>`.
- Навыки этапов подключены из `.claude/skills/`, роли субагентов — из `.claude/agents/`. Это копии `skills/` и `agents/`: правь оригиналы, затем выполни `python3 strateg.py sync`.
- Для поиска в открытых источниках используй встроенные поиск и загрузку страниц; найденную страницу сохраняй через `python3 strateg.py extract <имя> web <URL>`, чтобы у неё были копия и номер SRC.
- Картинки, скриншоты и кадры видео смотри сам через чтение файла.
