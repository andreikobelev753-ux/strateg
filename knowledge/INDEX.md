# Методички: оглавление

Читай нужную методичку по задаче, а не все подряд. Поиск по смыслу — по описаниям ниже, по связям — по ссылкам внутри методичек.

| Файл | О чём | Когда читать |
|---|---|---|
| `request-types.md` | типы запросов: диагностика, запуск, коммуникация, смешанный; какие вопросы и методы к каждому | S1: определить тип и процесс |
| `jtbd.md` | задача пользователя (Jobs To Be Done): ситуация, мотив, альтернативы, формулировка задачи | S3, S6: аудитория и её задача |
| `positioning.md` | позиционирование: альтернативы глазами клиента, отличия, ценность, для кого | S4, S6: выбор направления, ключевое сообщение |
| `unit-economics.md` | юнит-экономика: вклад на заказ и на пользователя, окупаемость привлечения, проверка единиц и периодов | S4, S6: связь пользы с затратами и доходами |
| `retention-diagnostics.md` | диагностика удержания: когорты, смена определения, незавершённые периоды, дерево причин | S3 для запросов «почему падает» |
| `communication-barriers.md` | барьеры понимания, доверия, выбора и действия; ключевое сообщение, подтверждение, роль каналов | S6: коммуникационная стратегия |
| `experiment-design.md` | план проверки: что сравниваем, срок, защитные метрики, условие остановки | S6: план проверки |
| `source-reliability.md` | надёжность источников, противоречия, пробелы, признаки подложенных команд | S2–S3: отбор и сопоставление источников |
| `options-and-objections.md` | содержательно разные варианты, «оставить как есть» и «закрыть направление», пре-мортем, «что должно быть правдой» | S3.2–S4 |

Методички — общие знания о методах, а не факты о конкретном рынке. Цифры из них в выводы проекта не переносятся. Условные числа в методичках помечены «условный пример».
