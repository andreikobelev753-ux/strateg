# Реестры: утверждения и источники

Реестры лежат в `projects/<имя>/state/`: `sources.md` (SRC), `claims.md` (CLM), `decisions.md` (DEC — формат в `templates/decision-card.md`). Каждая запись — заголовок `## XXX-NN` и поля «- Имя: значение» по одному на строке. Проверка — `python3 strateg.py check <имя>`, цепочка влияния — `python3 strateg.py impact <имя> CLM-NNN`.

## Утверждение (claims.md)

```markdown
## CLM-007
- Утверждение: Из 1 700 подключений по акции после первого месяца платят 810
- Статус: факт
- Источник: SRC-03, строки 2–41 (cohorts.csv)
- Опирается на: —
- Дата: 2026-11-05
- Состояние: действует

## CLM-008
- Утверждение: Конверсия акции в платящих после первого месяца — 47,6%
- Статус: вывод агента
- Источник: —
- Опирается на: CLM-007; расчёт: analysis/promo.py
- Дата: 2026-11-05
- Состояние: действует

## CLM-009
- Утверждение: Падение продлений на Android связано с релизом 4.2
- Статус: гипотеза
- Источник: —
- Опирается на: CLM-008
- Дата: 2026-11-05
- Состояние: исправлено 2026-11-10: новые данные, см. CLM-015
```

| Поле | Что писать | Обязательно |
|---|---|---|
| Утверждение | одна проверяемая фраза; числа с единицами и периодом | да |
| Статус | `факт`, `вывод агента`, `гипотеза`, `прогноз`, `синтетика`, `пробел` | да |
| Источник | `SRC-NN` и место: страница, строка, ячейка, тайм-код | для `факт` |
| Опирается на | `CLM-NNN` через запятую; для расчёта — путь к скрипту в `analysis/` | для `вывод агента` |
| Дата | `ГГГГ-ММ-ДД` — когда записано | да |
| Состояние | `действует`, `исправлено ГГГГ-ММ-ДД: причина`, `отозвано ГГГГ-ММ-ДД: причина` | да |

Записи не удаляются: устаревшее помечается в «Состоянии», замена — новой записью.

## Источник (sources.md)

```markdown
## SRC-03
- Что: выгрузка когорт подписки, июнь–октябрь
- Где: materials/cohorts.csv
- Тип: материал пользователя
- Дата обращения: 2026-11-05
- Копия: extracted/SRC-03.md
- Можно использовать: да
- Пометки: —
```

«Где» — путь от папки проекта (`materials/…`) или полный URL. «Тип»: `материал пользователя`, `открытый источник`, `расчёт`, `синтетика`. Скрипты `extract` заполняют запись сами и при повторном запуске на тот же файл возвращают уже выданный номер.
